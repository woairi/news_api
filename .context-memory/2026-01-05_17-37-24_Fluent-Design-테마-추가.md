# 작업 메모리: Fluent Design 테마 추가

## 📋 작업 개요
- **작업 일시**: 2026-01-05 17:37:24
- **작업 유형**: 기능 개발

## 🎯 작업 목표
기존 Material Design 3 테마만 지원하던 프론트엔드에 **Fluent Design System** 테마를 추가하고, 사용자가 두 디자인 시스템 간을 자유롭게 전환할 수 있는 UI를 구현합니다.

## 🔧 구현 내용

### 1. CSS - Fluent Design 색상 팔레트 추가
**파일**: `static/css/style.css`

#### Fluent Design Light Theme
- Primary: `#0078D4` (Microsoft Blue)
- Secondary: `#605E5C`
- Background: `#F3F2F1` (Fluent 특유의 회색빛 배경)
- Surface: `#FFFFFF`
- Typography: Segoe UI 폰트 사용
- Border Radius: 더 작고 날카로운 스타일 (8px, 4px, 2px)
- Elevation: 더 부드러운 그림자 효과

#### Fluent Design Dark Theme
- Primary: `#60CDFF` (밝은 파란색)
- Background: `#201F1E`
- Surface: `#292827`
- 다크 모드에 최적화된 색상 팔레트

#### 구현 방식
```css
[data-design="fluent"] {
    /* 라이트 테마 변수 */
}

[data-design="fluent"][data-theme="dark"] {
    /* 다크 테마 변수 */
}
```

### 2. HTML - 테마 선택 UI 추가
모든 페이지(`index.html`, `login.html`, `settings.html`)에 디자인 시스템 선택 기능 추가:

#### 네비게이션 바 업데이트
```html
<select id="designSelect" class="design-select" aria-label="디자인 시스템 선택">
    <option value="material">Material Design</option>
    <option value="fluent">Fluent Design</option>
</select>
```

- 다크/라이트 토글 버튼 옆에 배치
- 선택한 테마는 localStorage에 저장되어 페이지 간 유지됨

#### 초기화 스크립트
각 페이지 `<head>`에 디자인 시스템 즉시 적용:
```javascript
const savedDesign = localStorage.getItem('design') || 'material';
document.documentElement.setAttribute('data-design', savedDesign);
```

### 3. JavaScript - 테마 전환 로직
**파일**: `static/js/app.js`

#### State 관리
```javascript
let state = {
    // ...
    design: localStorage.getItem('design') || 'material'
};
```

#### 함수 추가
- `initDesign()`: 페이지 로드 시 저장된 디자인 시스템 적용
- `changeDesign()`: 사용자가 선택한 디자인으로 전환

```javascript
function initDesign() {
    document.documentElement.setAttribute('data-design', state.design);
    elements.designSelect.value = state.design;
}

function changeDesign() {
    const newDesign = elements.designSelect.value;
    document.documentElement.setAttribute('data-design', newDesign);
    localStorage.setItem('design', newDesign);
    state.design = newDesign;
}
```

### 4. 반응형 디자인
모바일 환경에서 테마 선택 드롭다운이 전체 너비를 차지하도록 조정:

```css
@media (max-width: 900px) {
    .actions {
        flex-wrap: wrap;
    }
    
    .design-select {
        order: -1;
        width: 100%;
    }
}
```

## 🎨 디자인 시스템 비교

- **색상**: 보라색 계열 (`#6750A4`)
- **폰트**: Roboto
- **모서리**: 둥글게 (16px)
- **그림자**: 강조된 elevation
- **느낌**: 대담하고 생동감 있는 디자인

### Fluent Design
- **색상**: 파란색 계열 (`#0078D4`)
- **폰트**: Segoe UI
- **모서리**: 날카롭게 (8px)
- **그림자**: 부드러운 elevation
- **느낌**: 미니멀하고 전문적인 디자인
